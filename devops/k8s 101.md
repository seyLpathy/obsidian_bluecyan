#### kubectl k8s命令行工具
配置kubectl
配置文件位置：C:\Users\<username>\.kube\config（windows)
容器只有被pod包装才能在k8s上运行
pod.yaml
```yaml
kind: Pod
apiVersion: v1
metadata:
	name: first-pod
	labels:
		project: qsk-book
spec:
	containers:
		- name: web
		image: nigelpoulton/qsk-book:1.0
		ports:
			- containerPort: 8080
```
 
#### kubectl常用命令
```
kubectl get pods 获取pod信息
kubectl apply -f pod.yml 创建pod
kubectl describe pod/svc first-pod 获取pod 详细信息(IP 为私有ip,无法与外界通讯)
kubectl delete svc/pod first-pod/svc-lb 删除pod或者svc
kubectl get pods -o wide
kubectl get deployments 获取部署状态
kubectl scale --replicas 5 deployment/qsk-deploy
kubectl rollout status deployment qsk-deploy
```

	name: svc-lb

	type: LoadBalancer
	port:
		-port: 5555    //接入端口
		targetPort: 8080  //转发端口
	selector:
		project: qsk-book
