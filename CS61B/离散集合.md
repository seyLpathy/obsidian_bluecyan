## construction for disjoint sets
**Property**
- ==connect(x,y)== Connects x and y
- ==isConnected(x,y)== return true if x and y are connected
**application**
- computational chemistry
- Kruskal's algorithm
### solution1
1. 用某种数据结构记录所有的基本（直接）连接 data strcture records all rudimentary connections
2. 利用遍历的方式确认俩元素之间是否存在连接
### solution2
- 利用集合的概念记录各元素的归属，既一个元素所属的集合由该元素的有连接的元素集合构成,元素如何连接将被忽略,只记录特定元素所属的集合  
- when number is large enough,you have iterate to find which set something belongs to
- the order of growth is N  
### solution3 (Quickfind)
用整数构成的列表代表存在关系的元素，其对应的列表中的值即为集合ID
### solution4 (quickUnion speed up connect base on soluton 3)
1. 为每一个元素指定根节点，类似树形结构
2. 为单一元素选定合适值作为根结点
**直接将第一个元素连接到第二元素的树形结构下回导致形成*巨大*的树形结构**
### solution5 (weighted quick union)
- 记录树的大小(size)
- 永远将小树并入大树(大小的标准为树的元素个数)
- 只有同等height的集合相merge的时候，height的长度按照对数增长
