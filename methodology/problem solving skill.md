# attitude
## 保持开放的心态
1. 你对问题的认知存在偏差
2. 你误判了问题的真实原因
3. 抛弃答案从新的角度出发
4. 你的认知和概念可能都是错的
## 观察
1. 奇怪突出的事物
2. 模式
3. 不应存在的事物
4. 缺乏的事物
## 问正确的问题
1. 真正发生的事物
2. 事物如何发生呢
3. 为实现目的，其效能如何
4. 移除某事物对结果的影响
5. 元素间的关系
6. 如何检验我的假定
尽可能用较少的假设去回答自己的问题
## 放慢速度
1. 用不同的方式去阐述问题
2. 经常回顾问题
## 不可懒惰
1. 仔细阅读材料
2. 观察也是不可或缺的过程
## 不必慌张
1. 坚信答案必然存在
2. 清晰和明确的思考
# 解决正确的问题
从概念层面去确定真正的问题
# 过程
## 解决问题
1. 收集尽可能多的信息
2. 从错误的输出中发现有用的信息
## 创造东西
1. 考虑所有可能的资源
2. 考虑事物的内在联系
## 评估现状
1. 改变输入是否改变输出
2. 是否可以获取更多的信息加强理解
3. 我的解答是否可以分解以判断各部分的正确性
## 检查假设
1. 自适应型的调整和重复
# 函数和目的
1. 强调事物抽象的特性
2. 尽量忽视事物的所呈现的状态而考略其本质
## 形成思维习惯
1. 用途是抽象特性的一种表现
2. 解构和串联事物之间的关系
## 通用策略
1. 分解问题并寻找模式和起点
2. 至少有三种解决方法
3. 旁观者清，当局者迷
4. 具体的实施
